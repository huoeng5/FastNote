# 桌面助手设计文档

## 一、项目概述

桌面助手是一款常驻后台的快捷信息记录工具，解决用户在使用微信助手等工具时，账号密码、网址、代码片段等信息难以整理和查找的痛点。

### 核心功能
- 快捷键 `Alt+F1` 唤起迷你输入窗口
- 快捷键 `Alt+F2` 直接截图
- 支持文本、截图、标签分类存储
- 数据保存到 Excel 文件
- 支持搜索、筛选、导出

## 二、技术架构

### 2.1 技术栈
- **语言**: Python 3.11+
- **GUI 框架**: PyQt6
- **Excel 处理**: openpyxl
- **图片处理**: Pillow
- **全局快捷键**: pynput
- **打包工具**: PyInstaller

## 三、数据存储设计

### 3.1 Excel 文件结构
**文件位置**: `%USERPROFILE%\DesktopAssistant\data.xlsx`

| 列名 | 类型 | 说明 |
|------|------|------|
| ID | 整数 | 自增唯一标识 |
| 创建时间 | 日期时间 | 自动记录 |
| 标签 | 文本 | 多个标签用空格分隔 |
| 内容类型 | 枚举 | text / screenshot / mixed |
| 文本内容 | 文本 | 纯文本内容 |
| 图片路径 | 文本 | 相对路径 `images/YYYYMMDD_HHMMSS_xxx.png` |
| 备注 | 文本 | 额外说明 |

### 3.2 图片存储
```
%USERPROFILE%\DesktopAssistant\
├── data.xlsx              # 主数据文件
├── images\                # 图片目录
│   ├── 20250115_143022_a1b2.png
│   ├── 20250115_143156_c3d4.png
│   └── ...
└── backups\               # 自动备份
    ├── data_backup_20250115.xlsx
    └── ...
```

## 四、界面设计

### 4.1 迷你输入窗口 (300×200)

```
┌────────────────────────────────┐
│  ┌──────────────────────────┐  │
│  │ 输入内容...              │  │  ← 多行文本框
│  │                          │  │    支持 Ctrl+Enter 保存
│  └──────────────────────────┘  │
│                                │
│  标签: [工作 账号          ]   │  ← 空格分隔标签
│                                │
│  [📷 截图]  [💾 保存] [📂管理] │  ← 三个按钮
│                                │
│  提示: Alt+F1 显示/隐藏       │  ← 底部提示
└────────────────────────────────┘
```

**交互细节**:
- 点击截图 → 窗口隐藏 → 截图模式 → 完成后窗口恢复
- Ctrl+Enter 快捷保存
- 窗口可拖动，记住上次位置
- 按 Esc 隐藏窗口

**快捷键（截图模式下）**:
| 按键 | 功能 |
|------|------|
| Enter / 双击 | 确认截图 |
| Esc | 取消截图 |
| 方向键 | 微调选区位置 (1px) |
| Shift+方向键 | 快速调整选区 (10px) |
| Ctrl+C | 复制选区到剪贴板（不保存文件） |
| Tab | 切换工具栏按钮 |
| Space | 按住空格拖动移动选区（类似PS） |

**调整手柄**: 选区四角和四边有8个调整手柄，鼠标悬停时显示对应光标形状

**管理界面功能**:

| 功能区域 | 功能说明 |
|---------|---------|
| **顶部工具栏** | 搜索框（实时搜索）、标签筛选下拉、类型筛选下拉（全部/纯文本/含图片）、新建按钮（打开迷你窗）、设置按钮 |
| **左侧列表区** | 显示记录摘要（图标+标题+标签+时间）、支持多选、右键菜单（编辑/删除/导出）、分页显示（每页20条） |
| **右侧详情区** | 显示完整内容、图片缩略图（点击放大）、标签编辑、操作按钮（编辑/删除/复制/导出Excel） |
| **底部状态栏** | 显示总记录数、当前页码、分页导航 |

**搜索功能**:
- 实时搜索（输入后300ms延迟触发）
- 搜索范围：标题、内容、标签
- 支持简单的与或语法：`工作 AND 邮箱`、`项目 OR 截图`
- 搜索结果高亮显示匹配关键词

**图片预览**:
- 详情区显示缩略图（最大 200×150，保持比例）
- 点击图片在新窗口中查看原图
- 支持滚轮缩放、拖拽平移
- 右键菜单：复制图片、保存到指定位置、在文件夹中打开
